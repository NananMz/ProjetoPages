PROJETO PAGES

Estrutura comercial, modelos de hospedagem, suporte e precificação otimizados para leitura móvel rápida.

Como funcionará o serviço

Opção 01
Hospedagem no GitHub Pages

Você cria as páginas em HTML/CSS/JS. Hospedagem direta no ecossistema sem custo mensal.

  • Sem custo mensal.
  • Custo para o cliente: R$ 0
URL do tipo: seunome.github.io/produto ou produto.github.io *Dependendo da configuração.
Opção 02
Domínio Próprio

Caso o cliente queira domínios como: ovarioazul.com ou projetox.com.br, etc.

  • Você compra o domínio e configura apontando para o GitHub Pages.
  • O cliente paga o valor do domínio + taxa de configuração.
  • Você recebe antes da compra.
